# Ally Stauffer — Portfolio

Personal portfolio built with Gatsby, React, and styled-components. The site highlights my work in software engineering, data infrastructure, machine learning, and research.

## Development

Use Node.js 14 (see `.nvmrc`), then install dependencies and start Gatsby:

```sh
yarn
yarn develop
```

Create a production build with `yarn build` and preview it with `yarn serve`.
